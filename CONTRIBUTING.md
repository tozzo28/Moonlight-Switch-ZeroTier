# Contribuir

Descreva o problema e os passos para reproduzi-lo. Separe resultados de testes de host
de resultados medidos no Switch. Para mudanças de transporte, execute `bash scripts/test-host.sh`.
Para código de plataforma, compile e teste no aparelho quando possível.

Preserve os avisos de autoria e licença. Não envie identidades ZeroTier, certificados de
pareamento, perfis pessoais, credenciais ou logs sem revisar e ocultar informações privadas.
Use exemplos fictícios e indique dependências novas e suas licenças.
