# Moonlight Switch + ZeroTier — v1.5.0-zerotier.1

Versão modificada do Moonlight-Switch com ZeroTier integrado ao aplicativo.

- Rede e PC configuráveis; ZeroTier desativado e campos vazios no primeiro uso.
- Sem identidade, certificados, hosts ou logs de outro usuário no pacote.
- ZeroTier Core e curl recompilados; transporte virtual local ao processo, sem MITM global.
- Configuração de pacotes de streaming baseada no peer selecionado.
- Testes de host aprovados e funcionamento no Switch informado pelo usuário.

Extraia o ZIP do aplicativo e copie a pasta `switch` para a raiz do cartão.
Veja o README e o guia de instalação para configurar sua própria rede e parear com Sunshine.
Dados já existentes no cartão não são apagados pelo pacote.

Anexos: ZIP do aplicativo, ZIP completo de fontes e SHA256SUMS.
O frontend base continua identificado como 1.5.0 dentro do aplicativo.
Esta não é uma versão oficial da ZeroTier, Nintendo ou XITRIX.
